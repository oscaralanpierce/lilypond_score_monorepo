# Escalas e Arpejos para Guitarra Portuguesa (Lisboa)

Já temos neste _monorepo_ quatro projetos que consistem em exercícios para a guitarra
portuguesa:

* [escalas_maiores_guitarra_portuguesa](https://github.com/oscaralanpierce/lilypond_score_monorepo/tree/main/escalas_maiores_guitarra_portuguesa)
* [escalas_menores_guitarra_portuguesa](https://github.com/oscaralanpierce/lilypond_score_monorepo/tree/main/escalas_menores_guitarra_portuguesa)
* [arpejos_maiores_guitarra_portuguesa](https://github.com/oscaralanpierce/lilypond_score_monorepo/tree/main/arpejos_maiores_guitarra_portuguesa)
* [arpejos_menores_guitarra_portuguesa](https://github.com/oscaralanpierce/lilypond_score_monorepo/tree/main/arpejos_menores_guitarra_portuguesa)

O problema é que, para estudar mais profundamente uma tonalidade particular, é preciso mudar de arquivo quatro
vezes. Este projeto tenta resolver este problema pondo as escalas e arpejos juntos em apenas um diretório dentro
do _monorepo_.

Nesta partitura, as escalas e os arpejos são agrupados por tonalidade. Se bem que seja lógico, do ponto de vista
musical, agrupar cada tonalidade maior com a menor relativa, não as agrupámos deste modo. Em vez disso, como no
fado é mais comum as tonalidades maiores aparecerem ao lado das menores _paralelas_, todas as escalas e os arpejos
maiores são agrupados com as tonalidades menores paralelas deles.
